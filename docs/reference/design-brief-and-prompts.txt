ВИЗУАЛЬНЫЕ РЕШЕНИЯ
Графитовый интерфейс, холодный перивинкловый акцент, светлый холст. Две постоянные основные вкладки. Узкая навигационная полоса. Единые пиктограммы, границы и типографика. Большие области для кода и схемы, без постоянной широкой библиотеки фигур. Галерея хранит стили оформления, а не примеры алгоритмов.

ПРОВЕРЕННЫЙ ПРИМЕР
int sumOdd(int n) {
    int s = 0;
    for (int i = 1; i <= n; ++i) {
        if (i % 2 == 0) continue;
        s += i;
    }
    return s;
}
На основных диаграммах проверены направления: продолжение цикла ведет к ++i; обратная стрелка — к i <= n, а не к i = 1; ложный выход внешней проверки — к return s; return s — к окончанию. Это визуальная проверка использованного примера, не проверка будущего анализатора C++.

MOTION ДЛЯ БУДУЩЕГО ПРОТОТИПА
• Hover и нажатие: 100–160 ms, изменение цвета/яркости без сдвига компоновки.
• Раскрытие контекстной панели и галереи: 180–240 ms, короткое затухание и малое смещение.
• Связь кода и блока: спокойная подсветка соответствующей строки и фигуры.
• Упорядочивание: 200–350 ms, плавное перемещение узлов с сохранением пространственной связи, прерываемое новым действием.
• Reduced motion: отключение перемещения и масштабирования как декоративной анимации.
В PNG анимации не воспроизводятся. Их поведение проверяется отдельно в интерактивном прототипе. Приложение и прототип сейчас не реализованы.
