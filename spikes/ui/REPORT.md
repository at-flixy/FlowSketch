# Проверка интерфейса первого прототипа FlowSketch

Дата: 13 октября 2026, Asia/Bishkek. Проверен React/TypeScript-интерфейс через реальный Codex In-app Browser по `http://127.0.0.1:1420/`. Снимки в `evidence` получены из браузера, а не сгенерированы. Это отдельная проверка UI; она не подтверждает native-анализ, файловые диалоги или приёмку Windows-поставки.

Прочитаны AGENTS.md, ui-ux-pro-max, ТЗ и три принятых макета. Сохранены графитовые поверхности, спокойный перивинкловый акцент, светлый холст и два основных режима. Поиск design-system дважды вернул неприменимый landing pattern; структура страницы и палитра из него не применялись. Использованы подходящие рекомендации Minimalism, видимого фокуса, ограничения анимации, ошибок у поля и клавиатурной навигации.

## Реализовано

- Локальный Monaco с C++ syntax highlighting, editor Worker и локальными шрифтами IBM Plex Sans / JetBrains Mono. Подсветка не сообщает о корректности C++.
- Реальные Tauri-команды выбора .cpp и проекта, native discovery/build/cancel, выбор функции. В браузере анализ явно отказывает с `ANALYSIS_FAILED`; пустая схема не заменяется демонстрационным успешным графом.
- Защита от ответов старого requestId / sourceRevision, кэш по выбранной функции, сохранение предыдущей схемы с меткой устаревания после изменения кода. Экспорт доступен только для готовой текущей сцены.
- Привязка Monaco к UTF-8 диапазонам через перевод в UTF-16. Выбор блока подсвечивает код; изменение курсора выделяет наиболее узкий содержащий диапазон. Выбор блока сохраняет фокус холста для клавиатурной навигации.
- Режим оформления: шрифт 12–24, цвета типов блоков / текста / линий / фона, толщина 1–4; автоматическая раскладка. Тип и выражение блока доступны для чтения.
- Четыре встроенных стиля, последние и пользовательские шаблоны; предпросмотр на существующем графе отдельным layout controller, применение и отмена; локальная библиотека без исходного C++. Undo/Redo хранит снимки до 100 действий.
- Проект сохраняет исходник, выбранную функцию и стиль. Открытие проекта восстанавливает их, затем требует нового анализа; импортированный JSON-граф не принимается как готовый.
- SVG export из той же сцены. Нативные кнопки окна и drag region, Ctrl+Enter / Ctrl+S / Ctrl+Shift+S / Ctrl+N / Ctrl+O, Undo/Redo оформления, Escape. Проверка несохранённых изменений при замене проекта и закрытии окна.

## Проверено в браузере

| Проверка | Наблюдение |
|---|---|
| 1440×900 | Редактор и холст рядом, отдельная панель оформления; галерея полностью помещается |
| 1100×768 | Раздельный вид; редактор 390 px, холст 616 px; document width = 1100 |
| 640×480 | Источник / холст переключаются; свойства открываются поверх холста; основные действия и галерея помещаются без горизонтальной прокрутки |
| Кнопка построения при 640×480 | После исправления compact-height её границы 57.8,423.2–625.2,465.2, внутри окна |
| Отсутствие native backend в браузере | Явная диагностика desktop required, число data-node-id = 0, SVG export disabled |
| Галерея с клавиатуры | Tab с последнего действия возвращает «Закрыть окно»; Shift+Tab с него возвращает «Применить шаблон»; DOM focus остаётся внутри dialog |
| Escape из галереи | Dialog закрыт; фокус возвращён на кнопку открытия галереи, подтверждено AX и DOM |
| История стиля | Размер 14 → 18 → Undo 14 → Redo 18, подтверждено select и AX |
| Несохранённые изменения | «Новый проект» после правки оформления открывает Save / Discard / Cancel; Cancel сохраняет проект |
| Контраст базовых ролей | Статический расчёт точных CSS цветов: 4.71–14.09; значения в evidence/browser-measurements.json |
| reduced motion | В коде единое media rule выключает animations / transitions и smooth scroll; смена ОС-настройки в браузере не эмулировалась |
| TypeScript / production assets | `npm run build` прошёл, Monaco worker / layout worker / C++ syntax module и шрифты поставляются локально |

В ходе проверки исправлены: clipping кнопки построения на 640×480, сжатие переключателя свойств до 1.6 px, потеря предыдущего стиля из-за чтения mutable ref в React updater, потеря trigger focus при двойном запуске effect в Strict Mode и уход фокуса при Tab из modal. Галерея использует независимый Worker-controller и не отменяет основную раскладку.

## Воспроизведение

1. `npm run build` и `npm run dev`.
2. Открыть локальный URL в браузере. Проверить размеры 1440×900, 1100×768 и 640×480.
3. Пройти режимы, открыть галерею, проверить Tab / Shift+Tab / Escape и возврат фокуса.
4. В оформлении сменить размер 14 на 18, выполнить Undo и Redo, проверить actual select.
5. Нажать построение в браузере: ожидается явный отказ desktop required и запрещённый экспорт.
6. Для проверки реальной цепочки ACC-05 запустить Tauri и использовать native-анализатор. Эта проверка относится к интеграционному отчёту root-агента.

Не проверены здесь: реальное чтение .cpp, native-анализ и отмена, сохранение/экспорт через системные диалоги, WebView2 keyboard/DPI и system-close, Canvas с настоящим runtime-графом, reduced-motion переключение ОС, весь профиль C++17 и чистая Windows-поставка. PDF, multi-page export, отдельные стилевые исключения блока, закрепление координат и операции rename/delete/import .flowstyle ещё не реализованы в UI прототипа.

Production build выдаёт предупреждение о main chunk около 3 MB minified и layout Worker около 1.8 MB. Это не подтверждает целевой budget запуска; профилирование и дополнительное разделение загрузки остаются задачами.
