# Changelog

## 0.1.0 — public source prototype — 2026-10-13

- Windows Tauri host with React/Monaco and a bounded native Clang LibTooling sidecar.
- Function selection, source-linked diagrams, measured geometry, automatic ELK layout and SVG export.
- Formatting mode, four themes, recent/custom styles, history and project files.
- Developer-machine native, Rust, scene and actual-window evidence; full v1 acceptance remains open.
- Public MIT source repository, bilingual README, contribution guide, versioned roadmap and SDK-free graph fixtures.
- Portable test/package helpers and CI for the public checkout. No public binary release yet.
